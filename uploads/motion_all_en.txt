================================================================================
07. PERFORMANCE

Prioritize performance over visual complexity.

Priority Implementation Methods

• Progressive Rendering
• SVG-based graphics
• CSS Transform Animation
• Opacity Animation
• Lightweight Motion
• Minimal GPU Load

Do not use:

• Three.js
• Heavy WebGL
• Large PNG assets
• Video-driven Hero sections
• Continuous particle animation systems

Maintain a premium visual experience while keeping the website as lightweight as possible.

================================================================================
08. ACCESSIBILITY

Support the following accessibility requirements:

• WCAG AA
• Keyboard Navigation
• Visible Focus States
• Reduced Motion
• ARIA Labels
• Minimum 44px Touch Targets

Do not create interactions that depend only on Hover.
