The Journey
발견에서 증명까지, 하나의 흐름으로 이어집니다. 

	1.	 발견 : 경계에서 놓치기 쉬운 단서를 찾습니다. 
	2.	정리 : 파편화된 기록을 이해할 수 있는 구조로 정돈합니다. 
	3.	연결 : 시간과 행위, 데이터의 관계를 하나로 잇습니다. 
	4.	증명 : 판단 가능한 사실과 가치로 완성합니다.

유락 3가지 키워드 

	•	 경계의 발견 ( Edge Discovery)  : 데이터가 생성되고 소멸하는 경계면에서 숨겨진 단서를 놓치지 않는 정밀한 탐색을 뜻합니다. 
	•	우주의 연결 ( Data Cosmos)  : 우수한 원시 데이터의 관계를 연결해 누구나 이해할 수 있는 하나의 가치로 완성하는 분석 허브를 의미합니다. 
	•	무결의 수호 ( Absolute Trust) : 증거의 무결성과 완전한 삭제 기술을 관통하는 유락의 신뢰 원칙을 상징합니다.

유락(UROCK)의 브랜드 정체성을 명확히 하고 개편될 웹사이트의 시각적 기준이 될 마케팅 컨설팅 기획안을 제안합니다.
제공해 주신 로고의 형상(U와 R이 결합된 견고한 심볼, 대칭적 안정감)과 지배적인 색상(신뢰감과 깊이감을 주는 네이비/블루, 혁신과 AI 기술력을 상징하는 네온 버건디/퍼플 믹스), 그리고 캐릭터 ‘Edge’와 ‘Eddy’의 가치관을 완벽히 융합했습니다. 다른 보안 업체들과 중복되지 않으며, 너무 기계적인 AI 느낌을 탈피하여 유락만의 서사를 담은 기획안입니다.
1. 유락(UROCK)만의 차별화된 브랜드 슬로건 추천
기존 로고의 형태적 결합(U+R)과 캐릭터들의 세계관(경계, 탐험, 우주)을 연결하여, 기술을 넘어 '가치와 진실을 완성하는 여정'을 인간적이고 묵직한 서사로 풀어냈습니다.
	•	메인 슬로건 1안 (서사 및 가치 중심 추천)‘데이터의 모든 경계에서 진실을 발견하고, 가치를 완성하다’ 
	•	기획 의도: 캐릭터 Edge의 '경계와 진실', Eddy의 '탐험과 가치 완성'이라는 철학을 온전히 담았습니다. 로고의 U(Universe, 우주)와 R(Reality, 진실)이 마주 보고 결합한 형태에서 착안하여, 파편화된 데이터 속에서 진짜 가치를 찾아내는 유락의 독점적 역할을 선언합니다.
	•	메인 슬로건 2안 (기술 및 신뢰 중심 추천)‘보이지 않는 단서에서 시작되는 완벽한 수호’ 
	•	기획 의도: 로고의 견고한 사각형 가이드라인과 닫힌 구조는 '철통같은 방어와 수호'를 의미합니다. 단순히 데이터를 분석하는 툴에 그치지 않고, 고객이 인지하지 못한 경계의 틈까지 지켜낸다는 든든함을 강조합니다.

2. 유락을 대표하는 핵심 키워드 3개 (캐릭터 컨셉 연계)
여타 보안 기업들이 흔히 쓰는 '혁신, 첨단, 완벽' 같은 추상적인 단어를 배제하고, 캐릭터들의 행동 가치관과 연계된 유락만의 고유 단어를 정의합니다.
	•	키워드 1: ‘경계의 발견 (Edge Discovery)’
	•	의미: 캐릭터 Edge의 가치관인 '탐색하고 발견하는 눈'에서 비롯되었습니다. 데이터가 생성되고 소멸하는 경계면(폐쇄망 현장, 모바일 기기 내부 등)에서 단 하나의 숨겨진 단서도 놓치지 않고 찾아내는 유락의 정밀한 기술력을 상징합니다.
	•	키워드 2: ‘우주의 연결 (Data Cosmos)’
	•	의미: 캐릭터 Eddy의 가치관인 '데이터 우주를 연결하고 분석하는 능력'을 뜻합니다. 무한히 쏟아지는 원시 데이터(Raw Data)들의 흐름을 서로 연결하여, 비전문가도 직관적으로 이해할 수 있는 하나의 유의미한 가치로 완성하는 분석 허브를 의미합니다.
	•	키워드 3: ‘무결의 수호 (Absolute Trust)’
	•	의미: 유락 로고의 견고한 형태감과 '진실을 지킵니다'라는 신념을 결합했습니다. 디지털 포렌식의 핵심인 법적 증거 능력(무결성)과 단 1비트도 남기지 않는 완전 무결한 데이터 삭제 기술을 관통하는 유락의 절대적 신뢰성을 뜻합니다.

3. 웹사이트에 반영할 공통 형태 및 UI 요소 추천
의미 없이 제작된 로고에 웹사이트 기획자가 스토리라인을 부여하는 방식입니다. 개발 및 퍼블리싱 단계에서 공통 컴포넌트로 활용할 시각적 가이드라인입니다.
	•	형태적 요소: ‘결합된 경계 (Connected Frame)’
	•	구현 방식: 메인화면의 배너나 솔루션 카드 뉴스를 디자인할 때, 완벽한 사각형이 아닌 '로고의 우측 상단 라운드 형태'를 딴 프레임을 공통으로 사용합니다.
	•	스토리텔링: '날카로운 경계(Edge)를 유연한 연결(Eddy)로 감싸 안아 완벽한 보안을 이룬다'는 서사를 시각적으로 보여줍니다.
	•	색감 및 그라데이션 요소: ‘심연의 단서 (Deep Cosmic Gradient)’
	•	구현 방식: 배경은 묵직하고 깊이감 있는 네이비 블랙(#0D1117 계열)을 기본으로 채택하고, 유저의 시선을 끌어야 하는 핵심 기술 지표나 강조 텍스트, 버튼(CTA)에는 로고의 '버건디 퍼플에서 네온 블루로 이어지는 그라데이션 라인'을 포인트 컬러로 활용합니다.
	•	스토리텔링: 데이터 우주의 어둠 속에서 유락의 AI 기술이 진실의 빛(단서)을 밝혀내는 극적인 효과를 연출하며, 웹 가독성과 SEO 점수를 동시에 확보합니다.
	•	시각적 인터랙션: ‘우주의 궤도 (Cosmic Orbit Line)’
	•	구현 방식: 웹사이트 스크롤 시, 배경에 보일 듯 말 듯한 미세한 그라데이션 선(Line)들이 유기적으로 움직이며 텍스트를 감싸안는 효과를 적용합니다.
	•	스토리텔링: Eddy가 탐험하는 데이터 우주의 연결 고리와 Edge가 지키는 보안 결계를 시각화하여, 딱딱한 보안 사이트가 아닌 하나의 거대한 서사가 흐르는 브랜드 저널 형태의 레이아웃을 완성합니다.
이 추천안은 우측 하단에 상시 고정될 [1:1 맞춤형 보안진단/도입 문의] 플로팅 버튼과도 유기적으로 연결됩니다. '경계에서 발견한 진실'을 확인한 유저들이 자연스럽게 리드(도환)로 유입되도록 동선을 유도하는 기준점이 될 것입니다.
